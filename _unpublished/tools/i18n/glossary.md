# Glossary and style guide — AI2ARCH English version

Working languages: Russian source → English target (C1, professional, no calques, no marketing noise).
This file is normative for every page under `/en/`.

## 1. Voice and mechanics

- Use US spelling: *program, organization, center, analyze, behavior*. Exceptions: proper names and quoted document titles.
- Address the reader as *you*. Avoid *one*, *we suggest*, *it is recommended* where a direct verb works.
- Prefer verbs to nominalizations: *analyze the site*, not *carry out the analysis of the site*.
- No rhetorical questions in body copy unless the Russian has one.
- No em-dash pile-ups. Use a colon, a comma, or a full stop.
- Keep sentence length close to the Russian. Do not merge bullet points.
- Do not add claims, numbers, names, or calls to action that are absent from the Russian.
- Keep the emoji that are part of the design. Keep the `→` and `↗` markers.
- UI labels are sentence case: *Apply*, *Curriculum*, *Fees*, except eyebrow labels set in uppercase by CSS.

## 6. Numbers, money, dates, time

- Prices stay in rubles: `5,000 ₽`, `18,900 ₽`, `14,900 ₽`, `3,600 ₽`. Thousands separator: comma. No currency conversion, no “from”.
- Academic hours: `22 academic hours`, `72 academic hours`.
- Durations: `2.5 weeks`, `4.5 weeks`.
- Dates: `November 16`, `November 5, 2026`, `November 5–8`. Weekdays: `Thu`, `Fri`, `Sat`, `Sun`.
- Time: `18:00–19:30 MSK`. In prose: `6:00–7:30 p.m. MSK` is not used; keep the 24-hour form and add “Moscow time (MSK)” once per page.
- File sizes and counts: `1.2 MB`, `39 pages`, `53 ways`, `25 of 53`.
- Percentages: `13%`.
- Ranges use an en dash: `5–10`, `2020–2022`.

## 9. Cyrillic policy for `/en/`

The only permitted Cyrillic in `/en/` is:

1. inside the exact marker “(in Russian)” next to a Russian legal document — the marker itself is English, so normally no Cyrillic;
2. in a quoted Russian document title, if quoting it is unavoidable — wrap it in `<span lang="ru">` and add an English translation;
3. in the hidden machine values listed in §8 (`course`, `certEligible`, form option values used as identifiers).

Everything else — visible text, `title`, `alt`, `aria-label`, `placeholder`, `value`, error messages, JS strings, CSS/JS comments, PDF metadata — must be English. Before committing, run:

```
grep -rInP '[\x{0400}-\x{04FF}]' en/ --include='*.html' --include='*.md'
```

and account for every remaining line in the report.

## 12. Terminology decisions without an exact English equivalent

These are deliberate choices; keep them identical across pages and list them in the final report.

- **справка** → *certificate of attendance*. Russian practice distinguishes it from the *удостоверение*; English has no exact pair, so the name states what the document confirms.
- **заочная экспертная оценка** → *remote expert review*. Literal *correspondence assessment* reads as mail-based and is not used in English course catalogs.
- **пояснительная записка** → *design report*, not *explanatory note* (a calque).
- **ОПР** → *space-planning solutions*, not *space-planning decisions*.
- **паспорт объекта** → *property data sheet*, not *object passport*.
- **инвестиционный паспорт** → *investment concept brief*, not *investment passport*.
- **планшет** → *presentation board*, not *tablet*.
- **ПЗЗ** → *land use and development rules (PZZ)*, the established rendering in English-language Russian planning literature.
- **ак. час** → *academic hour*; do not convert to clock hours.
- **контур** → *toolset*: the Russian metaphor of a contour does not survive translation.
- **ВКР** → *thesis* (the Russian final qualification work); *graduation thesis* at first mention if the sentence needs it.
