Module 1

What QGIS is and why architects use it

QGIS is a free, open-source geographic information system. For architects and urban planners it is a spatial analysis tool: working with base maps, overlaying data layers, and generating clean graphic diagrams.

🗺️

Georeferencing

All objects have precise coordinates. The diagram always matches the real territory.

📐

Exact scales

Any export comes with a set scale, frame, and grid. Control over every pixel.

🔗

Open data

OSM, Rosreestr, census data, DEM relief — everything loads directly.

🤖

AI-ready exports

PNG with a transparent background, crisp outlines, and a minimalist style — ideal for vision models.

03

Diagram types that AI models can read

Vision models analyze images through patterns and contrasts. A diagram must be readable, high-contrast, and semantically unambiguous.

1

Functional zoning

Color fills for zones, minimal text, clear boundaries. AI recognizes zones by color and needs a description of the legend. PNG 2000×2000 px.

2

Transport and pedestrian connections

Lines of different widths by hierarchy (arterial → street → path). AI reads the hierarchy well and analyzes connectivity.

3

Building typology diagram

Building outlines filled by development type. Minimalist style: white background, gray outlines, accent colors.

4

Heatmap

Gradient visualization of density. AI recognizes clusters and anomalies. Black or white background, not gray.

5

Relief / elevation diagram

Labeled contours or an elevation color scale. AI describes the elevation change and slope orientation accurately.

04

Style settings and export for AI

Styling principles for AI readability

  • ✓
    White or light background (#FAFAFA): AI models read contrast better on a light background
  • ✓
    Object outlines no thinner than 0.5 pt at the export scale
  • ✓
    Color fills with 40–80% saturation
  • ✓
    The legend is placed outside the frame or passed as text in the prompt
  • ✓
    Resolution: at least 150 DPI, 300 DPI recommended
  • ✓
    Format: lossless PNG is preferable to JPG

Export via Print Layout

1

Project → New Print Layout

A3 landscape. Add a Map item and lock the scale.

2

Setting the scale

In the map properties, set the scale manually (1:5000). Click "Lock".

3

Layout → Export as Image

PNG, 300 DPI. Disable "Antialiasing" only if outlines are doubled.

4

PDF export

PDF preserves vector objects. Use it for post-processing in Illustrator.

5

Batch export via Atlas

Generates a series of diagrams by object. Convenient for uploading a series to AI in one go.

# Export via Python Console from qgis.core import QgsProject, QgsLayoutExporter manager = QgsProject.instance().layoutManager() layout = manager.layoutByName("zoning_diagram") exporter = QgsLayoutExporter(layout) settings = QgsLayoutExporter.ImageExportSettings() settings.dpi = 300 exporter.exportToImage("/output/scheme.png", settings)
⚠️
For detailed diagrams, increase DPI to 400–600. Gemini Vision works with images up to 4096×4096 pixels.

Full workflow: from data to AI analysis

Setup takes 20% of the time; QGIS does the rest for you

One properly configured style → export any fragment in seconds.

1

Data collection

QuickOSM → buildings, roads, greenery by bbox. Cadastre from pkk.rosreestr.ru. Satellite basemap via XYZ Tiles.

2

Style preparation

Layer symbology: minimalist fills, clear outlines. Save the style (.qml) and apply it to any project.

3

Creating layouts

One layout per diagram type. Lock the scale. Set it up once and reuse it many times.

4

Export PNG at 300 DPI

Layout → Export as Image. File names with a code: zone_01.png, transport_01.png.

5

Upload to AI + prompt

Attach the PNG and paste the prompt with the legend and tasks. For series, upload sequentially.

6

Iterating on feedback

Identify the key findings. Return to QGIS, adjust the diagram, export v2. Repeat.

Result: what the QGIS + AI combination delivers

An accurate base map + vision models = fast pre-design analysis, justified decisions, and generated text descriptions for land use and development rules (PZZ), design briefs, and presentations, without manually describing every drawing.

Fundamentals of working with AI tools for architects

What is an AI model?

An AI model is a tool that helps an architect work faster. It does not replace the specialist and does not make decisions for them. It can make mistakes, invent facts, and does not know all building codes. Any result must be verified.

AI tools are most useful for:

  • ✓
    Finding ideas
  • ✓
    Creating first concepts
  • ✓
    Selecting references
  • ✓
    Making rough visualizations
  • ✓
    Writing and editing texts
  • ✓
    Automating routine tasks

Main types of AI tools

📝

For working with text

Used for finding ideas, writing project descriptions, analyzing documents, drafting design briefs, and editing texts.

What is a prompt?

A prompt is a request or instruction that we give an AI tool. The better the prompt, the better the result.

Formula for a good prompt: ROLE + CONTEXT + TASK + EXAMPLES + FORMAT + TONE

1

Role

Who should the AI tool be?

For example: an architect, an urban planner, an interior designer.

2

Context

What is happening? What project are you working on? What constraints apply? Who is the project for?

3

Task

What exactly needs to be done?

Come up with a concept, write text, analyze a document, create a visualization.

4

Examples

Show a sample or describe what to follow.

5

Format

How should the answer look?

A list, a table, text, a presentation.

6

Tone

What style of answer do you need?

Formal, plain, academic, friendly.

Sample assignment: a playground in Elista

ROLE

You are an architect and landscape designer with experience creating public spaces and playgrounds.

CONTEXT

Elista, Republic of Kalmykia. Continental climate: hot dry summers, cold winters, many sunny days. The location is the central urban area or a park next to a Buddhist temple (khurul). A playground for children of different ages (2–12 years). It is important to reflect the region's cultural code and Buddhist aesthetics.

TASK

Develop a concept for a playground in a Buddhist style for the city of Elista. Propose an idea that links the play space to Kalmyk culture and Buddhist symbols. Describe the main zones and use scenarios, and select materials and landscaping elements. Propose a visual image for the playground.

REFERENCE EXAMPLES

  • ✓
    Use of a mandala in the layout
  • ✓
    Elements of Buddhist symbolism (lotus, dharma wheel, stupas) in the play forms
  • ✓
    Kalmyk ornament in paving and small architectural forms
  • ✓
    Wood, stone, natural materials
  • ✓
    Prayer flags and wind chimes as part of the environment
  • ✓
    Zones for quiet play and meditation
  • ✓
    Color palette: red, yellow, blue, white (the colors of Buddhist flags)

RESULT FORMAT

Overall playground concept (description of the idea and cultural reference).

TONE

Professional, creative, culturally sensitive. With emphasis on children's safety, environmental friendliness, authenticity, and connection to the Buddhist tradition of Kalmykia.

In the "Result format" item, specify the master plan separately, and add the necessary details to the request (scale, zone schedule, legend).

Common prompting mistakes

✗ The request is too short

"Make a presentation." The AI tool knows neither the topic, nor the style, nor the audience.

✗ No context

The AI tool does not know what project you are working on.

✗ Expecting a perfect result on the first try

Working with an AI tool is a dialogue and several iterations.

✗ Trusting the AI tool completely

Always verify facts, regulations, and conclusions.

💡
The main rule: An AI tool cannot read minds. The more thoroughly and clearly you explain the task, the better the result.

Photoshop before generation: preparing a draft for the AI tool

Photoshop is not only for after generation: a high-quality source assembled by hand significantly improves the accuracy and controllability of the result that comes out of the AI tool.

✏️

A sketch as the basis of composition

A quick sketch of the volumes and placement of the object on the site sets the correct geometry and scene proportions for the AI tool.

🖼️

A collage of references

Combining several analogous images into one draft: materials, forms, and surroundings come together as a single starting point.

🎭

Masks for control areas

Marking the areas that the AI tool should change or, conversely, keep unchanged: the basis for inpainting.

📐

Correct perspective

Aligning lines and the horizon in the source: the AI tool holds perspective more accurately when it is set correctly from the start.

  • ✓
    A black-and-white or flat-color draft already sets the silhouette and scale of the future building
  • ✓
    A rough tonal underpainting (light/shadow map) helps the AI tool choose the right lighting for the scene
  • ✓
    Site context (neighboring buildings, the road, greenery) in the draft holds the scale and keeps the scene from "getting lost"
  • ✓
    A clean alpha channel around the object makes it easier to replace the background later during generation

What is Gamma.app

An AI service for assembling presentations

Gamma.app generates the structure and design of slides from a text description or project outline, saving you manual layout in PowerPoint and letting you focus on content.

Presentation assembly stages

1

Collecting project materials

QGIS diagrams (zoning, transport, relief), visualizations from Module 3, and text descriptions and analysis from AI tools.

2

Building the structure

Drafting a text outline for the presentation: introduction, site analysis, concept, visualization, conclusions.

3

Generating in Gamma.app

Uploading the outline or text to the service, choosing a template and visual style, and generating slides automatically.

4

Refining and styling

Replacing generated images with your own diagrams and visualizations, and adjusting the text and slide order.

5

Exporting the presentation

Saving the finished work as PDF or PowerPoint for the project review or sending to the client.
