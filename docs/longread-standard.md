# Стандарт лонгрида (эталон — тема 2.2)

Эталон: `docs/lectures/2.2.md` → `redev-read-income.html`. Остальные лонгриды собираются тем же конвейером.

## Сборка

1. Колода → картинки слайдов: `python3 tools/render-slides.py <колода.html> <images/slides/папка>`. Последний кадр — раздел «Промпты» колоды, если он есть.
2. Канон → страница: `python3 tools/build-longread.py <2.2 | 2.4 | …>`. Параметры лекции (файлы, главы, число слайдов, подписи, плейсхолдеры) заданы в словаре `LECTURES` в `tools/build-longread.py`.
3. Проверка: регрессия 2.2 (пересборка должна дать побайтно тот же файл), 0 ошибок в консоли, нет горизонтального скролла при ширине 390 px.

## Правила

1. **Промпты — и в слайдах, и в пособии.** В слайде строка `ПРОМПТ (на экран, вслух не читается[, подпись]): *«текст»*`. Тот же текст — в пособии, раздел «Промпты темы N» с кнопкой «Копировать».
2. **«Проверь себя» на утверждение.** На каждую главу 4 вопроса, 4 варианта, верный индекс, пояснение, `ref` — номер слайда внутри главы.
3. **C52 — единственный учебный объект.** Планы C52 ставятся на слайд, где фиксируются данные C52 (`c52_slides` в конфиге; для 2.4 — слайд 7). Пробелы — «нет данных: нужен документ».
4. **Тренажёр и реестр документов — опционально** (`trainer_after`, `gaps_at`). По умолчанию выключены для новых лекций, пока не решено иное.
5. **Лекция без «Сквозного примера»** (`example=False`), если канон его не содержит.
