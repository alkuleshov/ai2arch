# Demo Day · регламент


### Карта сборки

- 1. Сдача документа и видеопича.
- 2. Заочная оценка экспертов.
- 3. Встреча с разбором результатов.
- 4. Критерии оценки.
- 5. Условия удостоверения.

> Вывод: Demo Day завершает курс оценкой и разбором.

### Зачем Demo Day

- оценка показывает, выдерживает ли документ проверку;
- разбор объясняет, что усилить;
- без оценки курс не завершается;
- результат — обратная связь и удостоверение.

> Вывод: Demo Day проверяет документ и питч, а не выступление.

**Термины:**
- **Заочная оценка** — проверка работы по документу и видеопичу без защиты у доски. Проще: эксперты читают и смотрят без вашего рассказа.

### Как проходит оценка

- эксперты оценивают заочно по документу и видеопичу;
- встреча посвящена разбору результатов;
- критерии известны заранее;
- оценка не заменяет консультацию по проекту.

> Вывод: Оценка идёт по документу, а встреча — по результатам.

**Термины:**
- **Экспертиза** — проверка работы по заданным критериям. Проще: оценка по понятным правилам.

### Путь Demo Day

- сдаёте документ и питч;
- эксперты оценивают заочно;
- встреча с разбором результатов;
- выполненные условия — удостоверение.

> Вывод: Путь линейный: сдача, оценка, разбор, документ.

**Термины:**
- **Удостоверение** — документ о повышении квалификации по итогам курса. Проще: документ об окончании курса.

### Критерии экспертов

- полнота по карте сборки;
- согласованность цифр и картинок;
- честность данных;
- проверяемость источников;
- ясность питча.

> Вывод: Критерии проверяют документ, а не оформление.

**Термины:**
- **Карта сборки** — последовательность разделов итогового документа. Проще: порядок, по которому собран документ.

### Что сдаётся

- итоговый документ по карте сборки;
- видеопич 5 минут;
- задание №5 обязательно;
- любые 3 из заданий 1–4.

> Вывод: Задание №5 обязательно для всех.

**Термины:**
- **Задание №5** — итоговый документ и видеопич по объекту. Проще: финальная работа курса.

### Как получить удостоверение

- любые 3 из заданий 1–4;
- задание №5 обязательно;
- документ и питч сданы;
- условия курса выполнены.

> Вывод: Удостоверение выдаётся по выполненным условиям, а не по оценке.

**Термины:**
- **Удостоверение** — документ о повышении квалификации по итогам курса. Проще: документ об окончании курса.

### Что смотрят эксперты

- полнота по карте сборки;
- согласованность цифр и картинок;
- честность данных и пробелов;
- проверяемость источников и ясность питча.

> Вывод: Объём документа — небольшой, но полный по задачам.

**Термины:**
- **Экспертиза** — проверка работы по заданным критериям. Проще: оценка по понятным правилам.

### C52: пример оценки

- полнота — по карте сборки;
- согласованность — цифры и визуал;
- честность — ПЗЗ, БТИ, ТУ помечены как нет данных;
- проверяемость — источники в документе.

**Пример: C52: площадь 1 959,2 м² по ЕГРН; ПЗЗ, БТИ и технические условия — нет данных.**

> Вывод: C52 оценивается по тем же критериям, что и любой объект.

### Типичные ошибки

- документ не по карте сборки;
- цифры расходятся с таблицей;
- пробелы скрыты;
- питч не связан с документом.

> Вывод: Ошибки видны при заочной проверке.

**Термины:**
- **Заочная оценка** — проверка работы по документу и видеопичу без защиты у доски. Проще: эксперты читают и смотрят без вашего рассказа.
